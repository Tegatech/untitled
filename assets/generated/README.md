# Jagaville Generated Image Assets

This folder tracks the generated Jagaville visual asset set produced during the current design work.

The current packaged set contains **95 generated image files** covering:
- logos and wordmark explorations
- ID / passport backgrounds
- security / guilloche patterns
- passport and cultural stamps
- Republic of Jagaville seals
- coat-of-arms directions
- hoodie / portrait mockups
- Jagaville brand boards and presentation sheets

The binary originals are packaged separately as `jagaville-generated-images.zip` from the working session.

## Current locked / preferred directions

- Round JAGAVILLE logo
- Mask logo
- “Conquer the World!” handwritten motto
- Republic of Jagaville coat of arms: oil palm + crocodile, EST. 2018
- Republic seal
- Entry Approved / Cultural Clearance / Movement Cleared stamp family
- Pale blue / cream guilloche passport background

## Naming convention

Generated exploratory images keep their original working filenames so they can be traced back to the design session. Production-ready assets should be promoted into `assets/final-logos/`, `assets/mottos/`, `assets/passport/`, `assets/stamps/`, or `assets/coat-of-arms/` once approved.
